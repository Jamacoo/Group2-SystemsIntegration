Setup Guide

How to run an exam. There is nothing to install on your computer.

Why this setup? To keep the system free of any charges, it runs on free cloud services: a free web host runs the system and a free cloud database stores the data. The trade-off is that free services go to sleep when nobody uses them, so the first page you open after a quiet period can take about a minute to load.

Running an exam

  1. Open the Admin Panel. When asked to log in, type any username and your instructor password.
  2. Under Add a New Exam, enter a name and your Google Form's embed link. To get it, open your Google Form, click Send, choose the <> (embed) tab, and copy only the address inside src="...".
  3. In Share with Students, copy the extension link and send it to your students first. The page it opens explains how to install the extension.
  4. Then send each student the exam's own link from the exam list. They must install the extension before they start.
  5. During the exam, watch the Dashboard and Live Activity pages.
Keep in mind
  • A few minutes before the exam, open the Admin Panel yourself. This wakes the system up, so your students do not have to wait.
  • If a page will not load, or students see an error, wait a minute and try again. If it keeps happening, tell the person who set the system up, because the database may need to be switched back on.
  • Keep your instructor password private. Anyone with it can see student results and change exams.
